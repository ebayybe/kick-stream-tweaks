# Kick Stream Tweaks — Registro de cambios

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## Versión 1.2.0 — 2026-10-07

Esta versión amplía el guardado de calidad y volumen con un conjunto completo de ajustes para el reproductor y los canales.

### Added

Incluye perfiles y canales guardados, efectos de sonido, notificaciones y diagnóstico. También añade estilos del panel, temporizador, atajos, importación y exportación, navegación por teclado y opciones de accesibilidad.

### Fixed

Se corrigió la aparición de ventanas vacías o simultáneas, avisos vacíos, etiquetas largas y variables de calidad.

### Compatibility

La actualización desde 1.1.0 conserva los ajustes. Los datos permanecen localmente; el comprobador no instala versiones automáticamente.
