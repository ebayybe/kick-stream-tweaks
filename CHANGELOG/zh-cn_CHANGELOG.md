# Kick Stream Tweaks — 更新日志

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## 1.2.0 版本 — 2026-10-07

此版本将画质和音量记忆功能扩展为完整的播放器与频道设置工具。

### 功能

新增频道配置和已保存频道、音效、通知与诊断功能，并提供面板样式、睡眠计时器、快捷键、导入/导出、键盘导航和无障碍选项。

### 修复

修复空白或重叠窗口、空通知、长文本标签及画质占位符替换问题。

### 兼容性

从 1.1.0 升级时会保留设置。数据仅保存在本地；更新检查不会自动安装版本。
