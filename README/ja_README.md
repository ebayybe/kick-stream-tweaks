# Kick Stream Tweaks

**あなたの Kick プレーヤー、覚えています。** 品質、音量、速度は、高速で完全にローカライズされたコントロール パネルにより、すべてのストリームで自動的に復元されます。

<a id="features"></a>
## 特徴

- **こだわりの品質。** ライブと VOD の品質を一度選択してください。これはすべての新しいストリームに適用されます。正確な品質が不足している場合、スクリプトは次に低い品質 (または自動) に戻ります。
- **安定した音量。** 音量とミュートはストリームごとに復元され、大音量の警告とプレーヤーとの同期を保つライブ スライダーが表示されます。
- **チャンネルごとのプロファイル。** ストリームを開き、**このチャンネルを保存**を押すと、そのチャンネルは独自の品質、音量、速度、サウンドを記憶します。グループとメモを追加したり、保存された設定を一時停止したり、オートメーションからチャンネルを完全に除外したりできます。
- **クイック プリセット。** ワンクリックで帯域幅を節約し、最高の品質で静かに視聴し、VOD を実行できます。
- **ツール。** スリープ タイマー、フォーカス ビュー、プレーヤーの再同期、ページ レイアウト コントロール (チャットの非表示、左側のメニューの折りたたみ)、およびすべての自動変更を一時停止するセーフ モード。
- **フリーズ アラーム。** タブが最小化されている場合でも、プレーヤーがフリーズするか黒い画面が表示されると、大音量のアラームが再生され、通知が表示されます。
- **クイック請求ボタン** ワンクリックで報酬を請求できる、ドラッグ可能なフローティング ボタン。 4 つのデザイン、5 つのアイコンまたは独自の画像、調整可能なサイズと不透明度。
- **報酬の自動請求。** オプション: Kick の報酬通知を待ち (またはスケジュールを確認し)、利用可能なものを請求して、ウィンドウを再度閉じます (デフォルトではオフ)。
- **サイレント再生。** プレーヤーをミュートせずにストリームを沈黙させ、バックグラウンド タブで再生を続けます。グローバルに、または保存されたチャンネルごとに設定します。
- **アラート** ドラッグ、サイズ変更、ミュートが可能な通知に加え、イベントごとの音量を備えたオプションのサウンド効果。
- **再設計されたインターフェイス。** グループ化されたサイドバー、設定検索、明るいテーマと暗いテーマ、アクセントカラー、コンパクトモード、テキストの拡大縮小、およびハイコントラスト。
- **あなたがコントロールできるアニメーション。** ライブ プレビュー、3 つのプリセット、個別のオープニング、ホバー、インジケーター効果。システムの「動きを減らす」設定を尊重します。
- **38 言語** の国旗付き。インターフェイスは初回実行時にブラウザ言語に従い、その後の選択を記憶します。
- **仕様によりプライベートです。** すべてがブラウザ内に残ります。テレメトリやネットワーク リクエストはありません。

<a id="installation"></a>
## インストール

1. ユーザースクリプトマネージャーをインストールします。 [Tampermonkey](https://www.tampermonkey.net/) または [Violentmonkey](https://violentmonkey.github.io/)。
2. 開ける [`kick-stream-tweaks.user.js`](https://github.com/ebayybe/kick-stream-tweaks/raw/main/kick-stream-tweaks.user.js) そしてインストールを確認します。
3. 任意のストリームを開きます [kick.com](https://kick.com) そして **F2** を押します。

アップデートはユーザースクリプトマネージャーによって配信されます。を視聴することもできます [Releases](https://github.com/ebayybe/kick-stream-tweaks/releases) ページ。

## チャンネルの設定を保存する

1. カスタマイズしたいチャンネルのストリームを開きます。
2. パネルを開きます (`F2`) を押して、**このチャンネルを保存** (**チャンネル** ページ、または **再生** ページのヒントから) を押します。現在の品質、音量、速度、サウンド設定がそのチャンネルに保存されます。
3. ボタンの下にあるエディターで微調整します。これらは、そのチャネルを開くたびに自動的に適用されます。

プロファイルを削除せずに一時停止するには、[**このチャンネルに保存された設定を適用**] スイッチを使用します。プロファイルを削除するには、[**削除**] スイッチを使用します。保存されたすべてのチャンネルは **チャンネル → 保存されたチャンネル** にリストされ、ここで検索、並べ替え、ピン留め、グループ化、メモの追加、バックアップと復元を行うことができます。

## 設定マップ

| グループ | ページ | 中には何が入っているのか |
| --- | --- | --- |
| プレーヤー | **再生** | プリセット、ライブ/VOD品質、フォールバック、音量、ミュート、大音量警告、速度 |
| プレーヤー | **チャンネル** | 現在のチャンネル プロファイル、保存されたチャンネル、検索、グループ、メモ、バックアップ |
| プレーヤー | **ツール** | スリープ タイマー、ページ レイアウト、特典の自動請求、クイック請求ボタン、フリーズ アラーム、クイック アクション、フォーカス ビュー |
| アラート | **お知らせ** | 邪魔しないでください、サイズ、継続時間、不透明度、位置、履歴 |
| アラート | **音** | マスタースイッチとボリューム、イベントごとのスイッチ、ボリュームとプレビュー |
| インタフェース | **外観** | テーマ、パネルスタイル、アクセントカラー、濃度、コントラスト、ぼかし、文字スケール、言語 |
| インタフェース | **アニメーション** | ライブプレビュー、プリセット、オープニング/ホバー/インジケーター効果、速度 |
| インタフェース | **ショートカット** | メニューホットキーとアクションホットキー |
| システム | **診断** | ライブステータス、品質スキャン、競合チェック、セーフモード、アクションログ |
| システム | **データと概要** | エクスポート、インポート、元に戻す、リセット、バックアップ、リンクの復元 |

すべてのスライダーは、マウス ホイールをホバーしているときにホイールにも反応します。パネルの上部にある検索ボックスを使用して、名前で設定を検索します。検索は英語の名前も理解するため、どのインターフェイス言語でも同様に機能し、そこに入力されたキーがページに到達することはありません。

## クイッククレームボタン

**ページの [ツール] → [クイック請求] ボタン**で有効にします。ストリーム上に小さなボタンが表示されます。

- **任意の場所にドラッグ**してください。その位置が記憶されます。
- **クリック**して報酬を受け取ります (報酬ウィンドウが開き、*請求* を押し、ウィンドウを閉じてストリームに戻ります)。
- キックの報酬通知が表示されると、**光って赤い点が表示されます**。それ以外の時間は非表示にしておくには、[*報酬が利用可能な場合のみ表示*] をオンにします。
- **スタイル** (オーブ、ピル、ガラス、フラット)、組み込み**アイコン**、または**独自の画像** (最大 2 MB の PNG、JPG、WebP、GIF、または SVG。背景が透明な正方形の画像が最適です)、**サイズ**、**不透明度**を選択します。ライブ プレビューにはすべての変更が表示されます。

このボタンは *報酬の自動請求* とは別になっているため、手動で、自動的に、またはその両方で請求することができます。

## ショートカット

| アクション | デフォルト |
| --- | --- |
| パネルの開閉 | `F2` |
| 通知の切り替え | `Alt+N` |
| チャットを切り替える | `Alt+C` |
| 左のメニューを切り替え | `Alt+S` |
| フォーカスビュー | `Alt+F` |
| 品質をリセットする | `Alt+Q` |

すべてのショートカットは **ショートカット** で元に戻すことができます。バインドは物理キーに従うため、どのキーボード レイアウトでも機能します。

## トラブルシューティング

- **品質は適用されません。** **診断**を開き、*診断の更新*を押してキックが提供する品質をスキャンし、*選択した品質を確認します*。チャネルが除外されている場合、またはセーフ モードがオンになっている場合は、ステータス行にその旨が表示されます。
- **特典は請求されません。** 自動請求はデフォルトでオフになっています。 **[ツール] → [特典**] で有効にして、*今すぐ請求** してみてください。これは、タブが表示されていてチャットに入力していないライブ チャネルでのみ機能します。 *通知* モードでは、スクリプトは Kick 自身の報酬バナーに反応します。
- **サイレント再生とオーディオ。** サイレント再生では、ビデオがブラウザーのオーディオ エンジン経由でゼロ ゲインでルーティングされます。サイトがそれをブロックしている場合は、パネルにその旨が表示され、通常の音はそのまま残ります。
- **何かが奇妙な動作をします。** *競合のチェック* を実行するか、問題のページで *セクションのリセット* を使用してください。
- **アップデート後、設定が正しくないように見えます。** **データと情報 → 元に戻す** または **バックアップの復元** を使用します。
- **バグが見つかりましたか?** *診断のコピー* を押して、 [new issue](https://github.com/ebayybe/kick-stream-tweaks/issues)。

## プライバシー

設定とチャンネル プロファイルは、kick.com のブラウザのローカル ストレージに保存されます。スクリプトはデータをどこにも送信せず、追加のアクセス許可を要求しません (`@grant none`）。

## 貢献する

問題やプルリクエストは大歓迎です。スクリプトは単一の自己完結型ファイルであるため、変更を試すためにビルド手順は必要ありません。 `kick-stream-tweaks.user.js` ページをリロードしてください。
