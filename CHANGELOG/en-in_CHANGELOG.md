# Kick Stream Tweaks — Changelog

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## Version 1.2.0 — 2026-10-07

This release expands quality and volume memory into a complete player and channel settings toolkit.

### Added

Includes channel profiles and saved channels, sound effects, notifications and diagnostics. It also adds panel styles, a sleep timer, shortcuts, import/export, keyboard navigation and accessibility options.

### Fixed

Fixed blank or overlapping dialogs, empty notifications, long labels and quality placeholder replacement.

### Compatibility

Settings are preserved when upgrading from 1.1.0. Data stays local; the update checker does not install updates automatically.
