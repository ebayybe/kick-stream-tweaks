# Kick Stream Tweaks — Izmaiņu žurnāls

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## Versija 1.2.0 — 2026-10-07

Šis laidiens paplašina kvalitātes un skaļuma saglabāšanu līdz pilnam atskaņotāja un kanālu iestatījumu rīku komplektam.

### Added

Pievienoti kanālu profili un saglabātie kanāli, skaņas efekti, paziņojumi un diagnostika. Pieejami arī paneļa stili, taimeris, īsinājumtaustiņi, importēšana un eksportēšana, tastatūras navigācija un piekļūstamības funkcijas.

### Fixed

Novērsta tukšu vai vienlaikus atvērtu logu, tukšu paziņojumu, garu etiķešu un kvalitātes vietturu problēma.

### Compatibility

Atjauninot no 1.1.0, iestatījumi tiek saglabāti. Dati paliek lokāli; atjauninājumu pārbaude tos neinstalē automātiski.
