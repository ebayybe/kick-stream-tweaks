# Kick Stream Tweaks — Historie změn

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## Verze 1.2.0 — 2026-10-07

Tato verze rozšiřuje ukládání kvality a hlasitosti na sadu nastavení přehrávače a kanálů.

### Added

Přidány profily a seznam uložených kanálů, zvukové efekty, oznámení a diagnostika. Nově jsou také styly panelu, časovač, klávesové zkratky, import a export, ovládání klávesnicí a funkce přístupnosti.

### Fixed

Opraveno zobrazování prázdných a souběžných oken, prázdných oznámení, dlouhých popisků a nahrazování proměnných kvality.

### Compatibility

Nastavení se při přechodu z verze 1.1.0 zachová. Data zůstávají v prohlížeči; kontrola aktualizací je sama neinstaluje.
