# Kick Stream Tweaks — Dziennik zmian

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## Wersja 1.2.0 — 2026-10-07

To wydanie rozszerza zapamiętywanie jakości i głośności o pełny zestaw ustawień odtwarzacza i kanałów.

### Added

Dodano profile i zapisane kanały, efekty dźwiękowe, powiadomienia oraz diagnostykę. Dostępne są też style panelu, timer, skróty, import i eksport, nawigacja klawiaturą i funkcje dostępności.

### Fixed

Naprawiono puste lub nakładające się okna, puste powiadomienia, długie etykiety i podstawianie jakości.

### Compatibility

Ustawienia są zachowywane przy aktualizacji z 1.1.0. Dane pozostają lokalne; sprawdzanie nie instaluje aktualizacji automatycznie.
