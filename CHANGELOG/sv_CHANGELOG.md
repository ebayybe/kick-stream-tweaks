# Kick Stream Tweaks — Ändringslogg

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## Version 1.2.0 — 2026-10-07

Den här versionen utökar sparad kvalitet och volym till en komplett verktygslåda för spelar- och kanalinställningar.

### Added

Innehåller kanalprofiler och sparade kanaler, ljudeffekter, aviseringar och diagnostik. Dessutom panelstilar, timer, kortkommandon, import/export, tangentbordsnavigering och tillgänglighetsalternativ.

### Fixed

Åtgärdade tomma eller överlappande dialogrutor, tomma aviseringar, långa etiketter och platshållare för kvalitet.

### Compatibility

Inställningar bevaras vid uppgradering från 1.1.0. Data stannar lokalt; uppdateringskontrollen installerar inget automatiskt.
