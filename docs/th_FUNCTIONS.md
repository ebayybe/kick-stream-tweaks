# Kick Stream Tweaks - การอ้างอิงฟังก์ชัน

ข้อมูลอ้างอิงสำหรับ Kick Stream Tweaks 1.3.1 โดยจะอธิบายว่าทุกฟังก์ชันทำงานอย่างไร การตั้งค่าถูกจัดเก็บอย่างไร สคริปต์จะขึ้นอยู่กับส่วนใดของหน้า Kick และวิธีการทำงานของแต่ละฟังก์ชันหรือเมธอดที่มีชื่อในสคริปต์ผู้ใช้ ดู [พื้นที่เก็บข้อมูล](https://github.com/ebayybe/kick-stream-tweaks) และ [บันทึกการเปลี่ยนแปลง](../CHANGELOG/en_CHANGELOG.md)

> ชื่อตรงกับแหล่งที่มา `void` หมายความว่าฟังก์ชันทำงานผ่านผลข้างเคียง วิธีการเขียนเป็น `Object.method` ใช้งานอยู่บนวัตถุนั้น ( `PlayerSync` , `Extras` , `GUI` , `Store` )

## สถาปัตยกรรม

userscript เป็นไฟล์ในตัวเองหนึ่งไฟล์ที่ทำงานที่ `document-start` ด้วย `@grant none` ไม่มีขั้นตอนการสร้างและไม่มีการร้องขอเครือข่ายของตัวเอง

| เลเยอร์ | วัตถุ / พื้นที่ | ความรับผิดชอบ |
|---|---|---|
| ข้อมูล | `TR` , `DIAG` , `FLAGS` , `LANG_NAMES` | การแปล 38 ภาษา ข้อความวินิจฉัยที่แปลเป็นภาษาท้องถิ่น SVG ที่เป็นธง และชื่อภาษา |
| การกำหนดค่า | `CONFIG` `DEFAULTS` | ค่าคงที่ (ตัวเลือก ขีดจำกัดการลองใหม่ ค่าที่ตั้งล่วงหน้า ส่วน) และการตั้งค่าเริ่มต้น |
| พื้นที่เก็บข้อมูล | `sanitizeSettings` , `Store` , `persist` | ตรวจสอบและบันทึกการตั้งค่าใน `localStorage` ; เก็บสแต็กเลิกทำในหน่วยความจำ |
| ตรรกะของผู้เล่น | `PlayerSync` | ค้นหาวิดีโอ คืนคุณภาพ ระดับเสียง ความเร็ว และโหมดเงียบ ดูการค้าง |
| ตัวช่วยหน้า | `Extras` | ปุ่มเค้าโครง การรับรางวัล รูปประจำตัวของช่อง และตัวกำหนดเวลาในเบื้องหลัง |
| อินเตอร์เฟซ | `PAGES` , `GUI` , ผู้ช่วยเหลือ | แผง Shadow-DOM, การแจ้งเตือน, เสียง, ปุ่มเคลมด่วนแบบลอย, ปุ่มลัด |

การไหลของข้อมูล: ลูป `PlayerSync.sync` 1.5 วินาทีจะอ่านการตั้งค่าที่มีผล (โปรไฟล์ช่องก่อน จากนั้นจึงทั่วโลก) ใช้กับเครื่องเล่นและเรียก `Extras.tick` การกระทำของผู้ใช้จะต้องดำเนินการผ่านตัวจัดการ `GUI` ซึ่งจะอัปเดตการตั้งค่าแบบ `persist` และส่งเฉพาะส่วนที่ได้รับผลกระทบไปยังเครื่องเล่น ( `media` หรือ `all` )

## พฤติกรรมการเผชิญหน้าผู้ใช้

| พื้นที่ | พฤติกรรม |
|---|---|
| ความคงอยู่ของผู้เล่น | บันทึกคุณภาพสด/VOD ระดับเสียง สถานะปิดเสียง โหมดเงียบ และความเร็ว จากนั้นนำไปใช้เมื่อตรวจพบสตรีมใหม่ การเปลี่ยนแปลงหน้าที่ทำด้วยตัวเอง (เช่น Kick การรีเซ็ตระดับเสียงเป็น 50%) จะถูกเปลี่ยนกลับ เฉพาะการกระทำของผู้ดูเท่านั้นที่อัปเดตค่าที่บันทึกไว้ |
| คุณภาพ | เลือกคุณภาพที่ต้องการผ่านเมนูเครื่องเล่น ย้อนกลับไปที่คุณภาพที่ต่ำกว่าถัดไป (หรืออัตโนมัติ) เมื่อไม่พร้อมใช้งาน และปิดเมนูอีกครั้ง การคลิกของผู้ใช้จริงเท่านั้นที่จะสอนสคริปต์ถึงคุณภาพ "ใช้ล่าสุด" ใหม่ |
| ระดับเสียงและการเล่นแบบไม่มีเสียง | ระดับเสียงและการปิดเสียงจะได้รับการกู้คืนต่อสตรีม การเล่นแบบไม่มีเสียงจะกำหนดเส้นทางวิดีโอผ่านกลไก Web Audio ในอัตราขยายเป็นศูนย์ ดังนั้นสตรีมจะเล่นในแท็บเบื้องหลังโดยไม่ถูกปิดเสียง |
| โปรไฟล์ช่อง | **บันทึกช่องนี้** จะจัดเก็บคุณภาพ ระดับเสียง ความเร็ว และเสียงปัจจุบันสำหรับช่องที่กำลังรับชม โปรไฟล์ยังเก็บบันทึกย่อ กลุ่ม สถานะพิน อวตาร และธงที่เปิดใช้งาน/ยกเว้น |
| ค่าที่ตั้งล่วงหน้า | ประหยัดแบนด์วิธ คุณภาพดีที่สุด การรับชมแบบเงียบๆ และ VOD ใช้งานได้ในคลิกเดียว |
| แผง | `F2` หรือปุ่มลัดแบบกำหนดเองจะเปิดแผงความกว้างคงที่ (680 พิกเซล) พร้อมแถบด้านข้างที่จัดกลุ่ม การค้นหา รูปแบบ Kick และ Minimal ธีมสว่าง/มืด สีเฉพาะจุด 14 สีพร้อมตัวเลือกสี รูปแบบกะทัดรัด การเบลอฉากหลัง การปรับขนาดข้อความ คอนทราสต์สูงและการควบคุมภาพเคลื่อนไหว |
| ค้นหา | ไม่คำนึงถึงสำเนียง จับคู่ภาษาอินเทอร์เฟซและชื่อภาษาอังกฤษ และจับคู่ส่วนหรือชื่อการ์ด การกดแป้นพิมพ์ที่พิมพ์ในแผงไม่เคยไปถึงปุ่มลัดของ Kick |
| สไลเดอร์ | แถบเลื่อนทุกอันตอบสนองต่อการคลิก การลาก ลูกศรบนแป้นพิมพ์ และล้อเมาส์ |
| เสียง | สัญญาณ Web Audio สำหรับการทำงานของเมนู การเปลี่ยนแปลงการตั้งค่า คุณภาพความสำเร็จ/ล้มเหลว และการคืนค่าระดับเสียง โดยแต่ละรายการมีสวิตช์ การแสดงตัวอย่าง และระดับเสียง |
| การแจ้งเตือน | ข้อความที่แปลแล้วซึ่งสามารถลาก ปรับขนาด ทำให้โปร่งใส ปิดเสียงได้ (ห้ามรบกวน ปิดเสียงแบบเต็มหน้าจอ) และบันทึกไว้ในประวัติ |
| หยุดการปลุก | ตรวจจับผู้เล่นที่หยุดทำงานหรือหน้าจอสีดำ ส่งเสียงเตือนดัง (แม้จะอยู่ในแท็บที่ซ่อนอยู่ โดยไม่ขึ้นอยู่กับสวิตช์เอฟเฟกต์เสียง) และแสดงการแจ้งเตือน |
| รางวัล | ตัวเลือกการอ้างสิทธิ์อัตโนมัติจะรอการแจ้งเตือนรางวัลจาก Kick (หรือดำเนินการตามกำหนดเวลา) เปิดหน้าต่างรางวัล อ้างสิทธิ์สิ่งที่มีอยู่และปิด ปุ่มอ้างสิทธิ์ด่วนแบบลอยและลากได้จะทำเช่นเดียวกันในคลิกเดียว |
| เค้าโครง | ซ่อนแชทและยุบเมนูด้านซ้ายจากแผงหรือด้วยปุ่มลัด สามารถเลือกจดจำตัวเลือกสำหรับทุกสตรีมได้ |
| เครื่องมือ | ตัวตั้งเวลาปิดเครื่อง มุมมองโฟกัส (เต็มหน้าจอ) การซิงค์โปรแกรมเล่นอีกครั้ง และโหมดปลอดภัยที่จะหยุดการเปลี่ยนแปลงอัตโนมัติทุกครั้ง |
| การวินิจฉัย | สถานะปัจจุบัน, คุณภาพที่ตรวจพบ, ความละเอียดของวิดีโอ, การสแกนคุณภาพ, การตรวจสอบข้อขัดแย้ง, บันทึกการดำเนินการ และรายงานที่คัดลอกได้ |
| ข้อมูล | ส่งออก/นำเข้าการตั้งค่า เลิกทำ กู้คืนหลังจากรีเซ็ต สำรอง/กู้คืนช่องที่บันทึกไว้ |
| ความเป็นส่วนตัว | การตั้งค่า โปรไฟล์ บันทึก และประวัติจะยังคงอยู่ในพื้นที่เก็บข้อมูลของเบราว์เซอร์ ไม่มีอะไรถูกส่งไปที่ใดก็ได้ |

## การอ้างอิงการตั้งค่า

ค่าทั้งหมดได้รับการตรวจสอบโดย `sanitizeSettings` ; สิ่งใดก็ตามที่ไม่ถูกต้องจะกลับไปสู่ค่าเริ่มต้น มีการบังคับใช้ช่วง

### ผู้เล่น

| คีย์ | ประเภท/ช่วง | ค่าเริ่มต้น | ความหมาย |
|---|---|---|---|
| `autoQualityEnabled` | บูลีน | `true` | ใช้คุณภาพที่ต้องการโดยอัตโนมัติ |
| `preferredLiveQuality` , `preferredVodQuality` | `auto` , `1080p60` , `1080p` , `720p` , `480p` , `360p` , `160p` | `auto` | คุณภาพที่จะใช้สำหรับสตรีมสดและ VOD `auto` แปลว่า "จดจำตัวเลือกสุดท้ายของฉัน" |
| `lastLiveQuality` , `lastVodQuality` | เหมือนกัน | `auto` | คุณภาพสุดท้ายที่ผู้ชมเลือกด้วยมือ |
| `qualityFallback` | `lower` `auto` | `lower` | จะทำอย่างไรเมื่อไม่ได้คุณภาพที่ต้องการ |
| `autoVolumeEnabled` | บูลีน | `true` | กู้คืนและปกป้องโวลุ่มที่บันทึกไว้ |
| `volume` | 0–1 | `1` | ปริมาณที่บันทึกไว้ |
| `muted` | บูลีน | `false` | บันทึกสถานะปิดเสียงแล้ว |
| `silent` | บูลีน | `false` | การเล่นแบบเงียบ (กราฟเสียงที่ได้รับเป็นศูนย์, เครื่องเล่นไม่ถูกปิดเสียง) |
| `playbackRate` | 0.25–2.5 | `1` | ความเร็วที่บันทึกไว้ `1` ไม่เคยถูกบังคับ |
| `warnLoudVolume` , `loudVolumeThreshold` | บูลีน; 60–100 ขั้นตอนที่ 5 | `true` ; `85` | การเตือนระดับเสียงสูง |
| `safeMode` | บูลีน | `false` | หยุดการเปลี่ยนแปลงอัตโนมัติทุกครั้ง |
| `channelProfiles` | วัตถุมากถึง 200 | `{}` | โปรไฟล์ต่อช่อง (ดูด้านล่าง) |

ช่องโปรไฟล์ช่อง: `enabled` , `excluded` , `liveQuality` , `vodQuality` , `volume` , `muted` , `silent` , อัตรา `playbackRate` , `displayName` , `pinned` , `avatar` (เฉพาะ `https://…kick.com/images/user/…` URLs), `note` (240 ตัวอักษร), `group` (40 ตัวอักษร), `updatedAt` , `lastUsed`

### การแจ้งเตือนและเสียง

## หน้าการตั้งค่า ( `PAGES` )

| หน้า | สารบัญ |
|---|---|
| `playback` | คำแนะนำบันทึกช่องนี้ ค่าที่ตั้งล่วงหน้า คุณภาพ (ใช้อัตโนมัติ สด VOD ทางเลือก) ระดับเสียง (ใช้อัตโนมัติ แถบเลื่อน ปิดเสียง การเล่นแบบเงียบ คำเตือนเสียงดัง) และความเร็ว |
| `channels` | ขั้นตอนวิธีการทำงาน ช่องปัจจุบันที่มีปุ่ม **บันทึกช่องนี้** สวิตช์หยุดชั่วคราว/แยกและตัวแก้ไข จากนั้นรายการช่องที่บันทึกไว้ (ค้นหา จัดเรียง ปักหมุดตัวกรอง กลุ่ม แก้ไข/เสร็จสิ้น ลบ) พร้อมการสำรองและกู้คืน |
| `tools` | ตัวตั้งเวลาปิดเครื่อง เค้าโครงหน้า รางวัล (อ้างสิทธิ์อัตโนมัติ โหมด ดีเลย์หรือช่วงเวลา อ้างสิทธิ์ทันที) การตั้งค่าปุ่มอ้างสิทธิ์ด่วนพร้อมการแสดงตัวอย่างสด หยุดการเตือน และการดำเนินการด่วน |
| `notifications` | สวิตช์ ขนาด ระยะเวลา ความทึบ การแสดงตัวอย่าง การรีเซ็ตตำแหน่ง และประวัติ |
| `sounds` | สวิตช์หลักและระดับเสียง สวิตช์ต่อเหตุการณ์ ระดับเสียง และการแสดงตัวอย่าง |
| `appearance` | ธีม สไตล์ สีเน้น ความหนาแน่น คอนทราสต์ ขนาดตัวอักษร ความเบลอ การจัดกึ่งกลาง และภาษา |
| `motion` | การแสดงตัวอย่างแบบสด ค่าที่ตั้งล่วงหน้า และเครื่องมือเลือกสำหรับเอฟเฟกต์เปิด เอฟเฟกต์โฮเวอร์ ตัวบ่งชี้ ความเร็ว และภาพเคลื่อนไหวของไอคอน |
| `shortcuts` | ปุ่มลัดเมนูและปุ่มลัดการดำเนินการพร้อมการเชื่อมโยงใหม่ |
| `diagnostics` | สถานะ การสแกน รายงาน การตรวจสอบคุณภาพและข้อขัดแย้ง เซฟโหมดและบันทึกการดำเนินการ |
| `about` | เวอร์ชัน ลิงก์ ส่งออก/นำเข้า เลิกทำ กู้คืน และรีเซ็ต |

<a id="kick-page-dependencies"></a>
## เตะการพึ่งพาหน้า

สคริปต์นี้อาศัยมาร์กอัปปัจจุบันของ Kick หากเป็นไปได้จะใช้ไอคอน คุณลักษณะ และโครงสร้างแทนข้อความที่มองเห็นได้ ดังนั้นจึงยังคงใช้งานได้ในทุกภาษาอินเทอร์เฟซ หาก Kick เปลี่ยนแปลงคุณสมบัติการจับคู่จะหยุดทำงาน (ส่วนที่เหลือจะทำงานต่อไป)

| คุณสมบัติ | มันมองหาอะไร |
|---|---|
| คุณภาพ | `<video>` ที่มองเห็นได้ `button[aria-haspopup="menu"]` และ `[role="menuitemradio"]` |
| เค้าโครง | คอนเทนเนอร์ที่มี `data-sidebar` และ `data-chat` `[data-testid="sidebar-collapse"]` / `sidebar-expand` ปุ่มไอคอน `CollapseRight` ภายใน `#channel-chatroom` และปุ่มไอคอน `MessagesOutline` สำหรับแสดงแชท |
| แจ้งรับรางวัล | `video` ที่มีแหล่งที่มามี `reward-available` หรือการ์ด `[role="group"]` ที่มีวิดีโอ `daily-rewards` |
| การรับรางวัล | `button[aria-haspopup="dialog"][aria-controls]` (ไอคอนของขวัญ) กล่องโต้ตอบที่ควบคุม ( `data-state` ) เปิดใช้งานปุ่มอ้างสิทธิ์โดยมีเนื้อหา `.contents` และปุ่มปิดที่มีป้ายกำกับ . `.sr-only` |
| หยด | `#rewards-panel` รายการที่มี `[role="progressbar"][data-state="complete"]` และปุ่มเปิดใช้งาน |
| อวตาร | `img[alt]` องค์ประกอบที่มีแหล่งที่มาคือ `files.kick.com/images/user/…/profile_image/…` |

<a id="localization"></a>
## การแปลเป็นภาษาท้องถิ่น

ทุกป้ายกำกับ ข้อความช่วยเหลือ ข้อผิดพลาด กล่องโต้ตอบ และการแจ้งเตือนจะต้องผ่านตัวแก้ไขการแปลสำหรับ 38 ภาษา ปุ่มที่หายไปจะกลับไปเป็นภาษาอังกฤษ ข้อความอินเทอร์เฟซใหม่ได้รับการแปลเป็นภาษาที่รองรับทั้งหมดพร้อมกับฟีเจอร์ที่เพิ่มเข้ามา ตัวเลือกภาษาจะแสดงธงและชื่อพื้นเมือง อินเทอร์เฟซจะเป็นไปตามภาษาของเบราว์เซอร์ในการรันครั้งแรกและจดจำตัวเลือกที่ชัดเจนในภายหลัง

<a id="safety-privacy-and-compatibility"></a>
## ความปลอดภัยความเป็นส่วนตัวและความเข้ากันได้

- การตั้งค่าจะถูกฆ่าเชื้อก่อนการจัดเก็บ ค่าที่ไม่ถูกต้องจะกลับไปเป็นค่าเริ่มต้นที่ปลอดภัย
- ชื่อช่อง บันทึกย่อ ข้อความแจ้งเตือน และเอาต์พุตการวินิจฉัยจะถูกหลีกเลี่ยงก่อนที่จะแทรก HTML
- ไอคอนปุ่มแบบกำหนดเองจะถูกเข้ารหัสอีกครั้งจากผืนผ้าใบและจัดเก็บเป็น URL ข้อมูลของประเภทภาพที่อนุญาตเท่านั้น มันไม่เคยออกจากเบราว์เซอร์
- Shadow DOM แยกสไตล์ของสคริปต์ออกจาก Kick เหตุการณ์แป้นพิมพ์จากแผงควบคุมถูกแยกออกจากปุ่มลัดของ Kick
- การดำเนินการอัตโนมัติจะข้ามช่องที่ยกเว้น เซฟโหมด และองค์ประกอบของผู้เล่นที่ขาดหายไป การรับรางวัลจะไม่กดปุ่มเดิมสองครั้งในการวิ่งครั้งเดียวและรอในขณะที่ผู้ชมพิมพ์
- สคริปต์ไม่มีการร้องขอเครือข่าย การอัปเดตมาจากตัวจัดการสคริปต์ผู้ใช้หรือหน้าการเผยแพร่
- การตั้งค่าท้องถิ่นที่มีอยู่จะยังคงอยู่เมื่อย้ายจาก 1.1.0, 1.2.0 และ 1.3.0
