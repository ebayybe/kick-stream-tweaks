# Kick Stream Tweaks — Catatan Perubahan

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## Versi 1.2.0 — 2026-10-07

Rilis ini mengembangkan penyimpanan kualitas dan volume menjadi perangkat pengaturan lengkap untuk pemutar dan kanal.

### Added

Mencakup profil dan daftar kanal tersimpan, efek suara, notifikasi, serta diagnostik. Ditambahkan pula gaya panel, timer tidur, pintasan, impor/ekspor, navigasi keyboard, dan fitur aksesibilitas.

### Fixed

Memperbaiki dialog kosong atau bertumpuk, notifikasi kosong, label panjang, dan penggantian placeholder kualitas.

### Compatibility

Pengaturan tetap tersimpan saat memperbarui dari 1.1.0. Data tetap lokal; pemeriksa tidak memasang pembaruan otomatis.
