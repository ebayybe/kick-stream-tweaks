# Kick Stream Tweaks — Өөрчлөлтийн бүртгэл

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## 1.2.0 хувилбар — 2026-10-07

Энэ хувилбар чанар болон дууны түвшин хадгалах боломжийг тоглуулагч, сувгийн бүрэн тохиргооны хэрэгсэл болгож өргөжүүлэв.

### Added

Сувгийн профайл, хадгалсан суваг, дууны эффект, мэдэгдэл, оношилгоо нэмэгдсэн. Мөн самбарын загвар, унтах таймер, товчлол, импорт/экспорт, гарын удирдлага болон хүртээмжийн сонголтуудтай.

### Fixed

Хоосон эсвэл давхар цонх, хоосон мэдэгдэл, урт шошго, чанарын орлуулагчийн алдааг засав.

### Compatibility

1.1.0-ээс шинэчлэхэд тохиргоо хадгалагдана. Өгөгдөл хөтөчид үлдэнэ; шинэчлэлт шалгагч автоматаар суулгахгүй.
