# Kick Stream 调整 — 变更日志

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks) 的发行说明，这是一个可以记住 Kick 播放器首选项并添加可配置控制面板的用户脚本。

## v1.3.1 — 2026-11-06

> 针对每种语言和文本大小的布局强化、真正独特的简约风格、奖励和布局助手、玩家冻结警报和更智能的默认语言。

### 添加

- **播放器冻结警报。** 检测停滞的播放器或黑屏（视频时间在没有解码帧的情况下移动），播放响亮的警报声音并显示通知，即使选项卡最小化也是如此。可配置的检测时间（5-60 秒）、独立的声音切换和测试按钮。
- **自动领取奖励**（默认情况下关闭）：打开奖励窗口，领取可用的奖励，再次关闭它并返回到流。奖励面板中出现的掉落物也可以领取。包括*立即索赔*按钮。
- **奖励计划。** 默认情况下，脚本等待 Kick 自己的“领取奖励”通知并立即领取（可选择 0-60 秒的延迟），而不是轮询。还可以使用预定模式（每 5-60 分钟一次）。
- **快速领取按钮。** 流上的一个小浮动按钮，只需单击一下即可领取奖励。将其拖到任何地方（位置会被记住），选择四种设计之一（球体、药丸、玻璃、平面）、五个内置图标、大小和不透明度，可选择仅在奖励可用时显示它。当 Kick 的奖励通知出现时，它会发光并显示一个点。设置页面有实时预览。
- **您自己的图标。** 上传 PNG、JPG、WebP、GIF 或 SVG（最大 2 MB）作为按钮图标，可以选择填充整个按钮。该图像被重新编码为一个小方块并仅存储在您的浏览器中。
- **滑块上的鼠标滚轮。** 每个滑块都可以在悬停时使用鼠标滚轮进行调整，而无需滚动面板。
- **函数参考。** 新的 `en_FUNCTIONS.md` 记录了脚本所依赖的架构、每个设置、每个函数以及 Kick 页面的部分。
- **指导频道保存。** 分步“已保存频道的工作原理”卡、单个 **保存此频道** 按钮（用于存储您正在观看的频道的当前质量、音量、速度和声音）、播放中未保存频道的一键提示、确认吐司、列表中标有 *编辑* / *完成* 按钮以及用于暂停已保存设置而不删除它们的开关。
- **静音播放。** 使流静音而不使播放器静音，因此它会在后台选项卡中继续播放。适用于全局和每个已保存的频道（频道列表中显示 *Silent* 标签）。
- **多语言设置搜索。** 搜索不区分重音，并且还匹配英文名称，因此输入 `volume` 可以找到任何界面语言的设置。按部分或卡片标题搜索会显示整个部分。
- **页面布局控件**：隐藏聊天并从面板或使用热键（`Alt+C`、`Alt+S`）折叠左侧菜单，并提供记住每个流的布局的选项。
- **侧边栏、重置和帮助图标的图标动画**，带有自己的开关（也是动画预设的一部分）。
- **频道头像**从 Kick 中捕获并显示在已保存的频道列表中。
- 14 种强调色（原为 6 种）。
- 面板内确认对话框在每个浏览器中看起来都相同。

### 已更改

- **界面语言**现在在首次运行时遵循浏览器语言。一旦你选择了一种语言，它就会被记住。从旧版本迁移的设置会跟随浏览器，直到明确选择语言为止。
- 脚本现在从 `document-start` 开始，因此其键盘隔离在页面自己的侦听器之前注册。
- 设置行堆叠在一起（标签位于控件上方），因此无论语言、文本大小或面板宽度如何，文本都不会重叠或剪切。侧边栏标签环绕单词边界。
- 动画选择器被重建为带有图标的全宽行，因此适合长翻译。
- **最小**面板样式现在是平坦的方形，没有发光，边框被分隔线和下划线样式选择取代，因此与 **Kick** 的区别是明显的。
- 面板的固定宽度为 680 px（它会缩小以适应小窗口）。面板宽度设置和调整大小手柄已被删除，因此每个人的布局都是相同的。
- 当使用不同的强调色时，指示器动画标题不再显示“绿色”。

### 已修复

- 更改音量、静音、静音播放、自动音量或速度也会重新应用质量（重新打开质量菜单并显示通知）。这些设置现在只影响您更改的内容；仅当质量设置更改时才会重新应用质量。
- 在设置搜索中输入可能会触发 Kick 的热键（例如 Space 将流切换到全屏）。面板内的击键不再到达页面。
- 当 Kick 在重新加载后将播放器重置为自己的 50% 时，首选音量被覆盖，并且面板滑块显示 50%。页面本身所做的更改现在已恢复到您保存的卷中；只有你自己的行为才能更新它。
- 外观、动画和热键中的文本剪切和重叠（长标签、大文本尺寸、窄面板、长翻译）。
- 最小风格默默地禁用了背景模糊设置；模糊现在可以在两种风格中使用。
- 更改快速声明按钮的不透明度不会更新预览。
- 滑块对鼠标滚轮没有反应。
- 动画方块（“Scale”、“Pop”）溢出了卡片。
- 使用浏览器的本机对话框删除配置文件确认。
- 睡眠定时器芯片未本地化。
- 保存的频道不显示头像，当前频道在保存其个人资料之前不显示任何头像。

### 兼容性

- 从 v1.3.0、v1.2.0 和 v1.1.0 更新时，将保留现有设置和保存的频道。
- 该脚本仍然不发送遥测数据，也不发出自己的网络请求。

## v1.3.0 — 2026-11-03

> 全面重新设计、逻辑设置结构、重建的动画系统以及针对玩家自动化的一轮可靠性修复。

### 添加

- 重新设计的面板带有分组侧边栏：**播放器**（播放、频道、工具）、**警报**（通知、声音）、**界面**（外观、动画、快捷方式）和**系统**（诊断、数据及有关）。
- 新的**动画**页面：实时预览阶段、三个一键式预设（完整、缩小、关闭）以及用于打开效果（无、淡入淡出、滑动、缩放、流行）、悬停效果、指示器动画和速度的单独选择器。
- 节省带宽、最佳质量、安静观看和 VOD 的快速预设，立即应用。
- 质量选择器重新设计为芯片网格；速度、文本比例和睡眠计时器使用芯片和分段控件而不是下拉菜单。
- 内联频道管理器：搜索、排序、固定、分组、注释、每频道编辑和完整备份/恢复，所有这些都没有嵌套对话框。
- 内联声音设置，带有每个事件的开关、音量和预览按钮。
- 诊断中的质量扫描：打开播放器菜单，记录可用质量并再次关闭。
- 热键现在适用于任何键盘布局（它们与物理键匹配）。
- 打开的 Kick 选项卡之间的设置同步。
- 自定义颜色选择器旁边的强调颜色样本、更高的文本比例范围和首选减少运动保护。

### 已更改

- 设置以更精简的格式存储； 1.2.x 配置、热键和动画选择会自动迁移。
- 仅当播放速度不同于 1× 时才应用，因此 Kick 自己的实时边缘追赶不再被覆盖。
- 撤消历史记录保存在内存中，而不是写入本地存储。
- 声音事件、通知和热键共享一组一致的控件。
- “情景配置文件”选择器被一键预设取代。

### 已修复

- 应用质量后关闭播放器菜单不再有重新打开它的风险。
- 后备质量（例如 720p，而不是不可用的 1080p）不再覆盖为频道保存的首选质量。
- 只有对优质物品的真实点击才会更新“上次使用”的品质；自动点击将被忽略。
- 输入后设置搜索不再失败（事件目标在 Shadow DOM 中丢失）。
- 在一个选项卡中进行的更改无法再覆盖另一选项卡中的设置。
- 面板热键不再在非拉丁布局上中断。
- 诊断日志控件中的标签不正确，日语脚本标题中存在杂散的韩语单词。
- 隐藏选项卡时停止播放检查和流同步暂停。

### 已删除

- 无法针对 Kick 播放器进行验证或复制的功能：低延迟首选项、空闲时隐藏播放器控件以及基于 GitHub 的面板内更新检查（使用用户脚本管理器的更新或发布页面）。
- 过度设计的选项：保存的外观配置文件、部分显示/隐藏/重新排序、替代导航模式、兼容性和翻译覆盖检查、随机/滚动/部分动画、每个事件的通知持续时间、频道头像、组颜色、手动排序、批量选择、每个频道历史记录和自动清理。

### 兼容性

- 从 v1.2.0 和 v1.1.0 更新时，将保留现有设置和保存的频道。
- 设置保留在浏览器本地；该脚本不发送遥测数据或发出网络请求。

## v1.2.0 — 2026-10-07

> 将原始质量和音量助手扩展为完整的播放器设置工具包。

### 添加

- 每个通道的质量、音量、播放速度和静音状态配置文件。
- 保存的频道列表包含注释、组、配置文件编辑和导入/导出。
- 具有全局开关、单个事件开关、预览和每个事件音量的音效。
- 质量变化、恢复量和失败操作的通知。
- 具有清晰控制的通知历史记录、操作日志和诊断工具。
- 质量可用性检查、冲突检查和兼容性检查。
- 安全模式可暂时禁用自动播放器更改。
- 热键、面板拖动、面板大小调整和中心面板操作。
- Kick 和 Minimal 面板样式、紧凑的布局和动画控制。
- 睡眠定时器、全屏聚焦模式、播放器重新同步和播放控制。
- 导入/导出设置和通道配置文件。
- 键盘导航、文本缩放、屏幕阅读器公告和高对比度。
- 支持 38 种语言的界面本地化。

### 已修复

- 防止多个辅助对话框同时出现。
- 修复了声音设置窗口上方出现的空对话框。
- 忽略空通知消息而不是显示空白覆盖。
- 改进了窄面板和本地化布局上的长标签包装。
- 修复了通知中的 `{quality}` 和 `{q}` 占位符替换。
- 更新了面板内版本标签并更新了与 1.2.0 的比较。

### 兼容性

- 从 v1.1.0 更新时保留现有设置。
- 设置保留在浏览器本地；该脚本不发送遥测数据。
- 更新检查器读取最新的 GitHub 版本标签，并且不会自动安装更新。

## v1.1.0

最初的公共版本侧重于记住 Kick 上的视频质量和音量，将它们自动应用到新流，并提供 F2 设置面板。
