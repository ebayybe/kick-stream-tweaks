# Kick Stream Tweaks

**Kick 플레이어를 기억하세요.** 품질, 볼륨 및 속도는 빠르고 완벽하게 현지화된 제어판을 통해 모든 스트림에서 자동으로 복원됩니다.

## 특징

- **고착되는 품질.** 라이브와 VOD 품질을 한 번만 선택하세요. 이는 모든 새 스트림에 적용됩니다. 정확한 품질이 누락된 경우 스크립트는 다음 낮은 품질(또는 자동)로 대체됩니다.
- **고정된 볼륨.** 볼륨 및 음소거는 스트림마다 복원되며 큰 볼륨 경고 및 플레이어와 동기화되는 라이브 슬라이더가 포함됩니다.
- **채널별 프로필.** 스트림을 열고 **이 채널 저장**을 누르면 해당 채널이 자체 품질, 볼륨, 속도 및 사운드를 기억합니다. 그룹 및 메모를 추가하고, 저장된 설정을 일시 중지하거나, 자동화에서 채널을 완전히 제외하세요.
- **빠른 사전 설정.** 한 번의 클릭으로 대역폭, 최고 품질, 조용한 시청 및 VOD를 절약할 수 있습니다.
- **도구.** 절전 타이머, 포커스 보기, 플레이어 재동기화, 페이지 레이아웃 제어(채팅 숨기기, 왼쪽 메뉴 축소) 및 모든 자동 변경을 일시 중지하는 안전 모드.
- **알람 정지.** 탭이 최소화된 경우에도 플레이어가 정지하거나 검은색 화면이 표시되면 큰 알람을 울리고 알림을 표시합니다.
- **빠른 청구 버튼.** 클릭 한 번으로 보상을 청구할 수 있는 떠다니는 드래그 가능한 버튼입니다. 4가지 디자인, 5가지 아이콘 또는 나만의 이미지, 조정 가능한 크기 및 불투명도.
- **보상 자동 청구.** 선택 사항: Kick의 보상 알림을 기다리고(또는 일정에 따라 확인) 사용 가능한 보상을 청구하고 창을 다시 닫습니다(기본적으로 꺼져 있음).
- **무음 재생.** 플레이어를 음소거하지 않고 스트림을 음소거하여 백그라운드 탭에서 계속 재생합니다. 전역적으로 또는 저장된 채널별로 설정하세요.
- **경고.** 끌기, 크기 조정, 음소거가 가능한 알림과 이벤트별 볼륨이 포함된 선택적 사운드 효과.
- **새롭게 디자인된 인터페이스.** 그룹화된 사이드바, 설정 검색, 밝은 테마와 어두운 테마, 강조 색상, 압축 모드, 텍스트 크기 조정 및 고대비.
- **사용자가 제어하는 ​​애니메이션.** 실시간 미리보기, 세 가지 사전 설정 및 별도의 열기, 호버 및 표시기 효과. 시스템의 "모션 감소" 설정을 존중합니다.
- **38개 언어** 플래그 포함. 인터페이스는 처음 실행 시 귀하의 브라우저 언어를 따르며 이후에는 귀하의 선택을 기억합니다.
- **비공개로 설계되었습니다.** 모든 것이 브라우저에 유지됩니다. 원격 측정도 없고 네트워크 요청도 없습니다.

<a id="installation"></a>
## 설치

1. 사용자 스크립트 관리자를 설치합니다. [Tampermonkey](https://www.tampermonkey.net/) 또는 [Violentmonkey](https://violentmonkey.github.io/).
2. 열려 있는 [`kick-stream-tweaks.user.js`](https://github.com/ebayybe/kick-stream-tweaks/raw/main/kick-stream-tweaks.user.js) 설치를 확인하세요.
3. 다음에서 스트림을 엽니다. [kick.com](https://kick.com) **F2**를 누르세요.

업데이트는 사용자 스크립트 관리자가 제공합니다. 당신은 또한 볼 수 있습니다 [Releases](https://github.com/ebayybe/kick-stream-tweaks/releases) 페이지.

## 채널 설정 저장

1. 맞춤설정하려는 채널의 스트림을 엽니다.
2. 패널을 엽니다(`F2`) 및 **이 채널 저장**을 누릅니다(**채널** 페이지 또는 **재생** 페이지의 힌트에서). 해당 채널에 대한 현재 품질, 볼륨, 속도 및 사운드 설정이 저장됩니다.
3. 버튼 아래의 편집기에서 세부 조정하세요. 해당 채널을 열 때마다 자동으로 적용됩니다.

프로필을 삭제하지 않고 일시중지하려면 **이 채널에 저장된 설정 적용** 스위치를 사용하고 프로필을 삭제하려면 **제거** 스위치를 사용하세요. 저장된 모든 채널은 **채널 → 저장된 채널** 아래에 나열되며, 여기에서 검색, 정렬, 고정, 그룹화, 메모 추가, 백업 및 복원이 가능합니다.

## 설정 지도

| 그룹 | 페이지 | 안에 무엇이 들어있나요? |
| --- | --- | --- |
| 플레이어 | **재생** | 사전 설정, 라이브/VOD 품질, 대체, 볼륨, 음소거, 큰 볼륨 경고, 속도 |
| 플레이어 | **채널** | 현재 채널 프로필, 저장된 채널, 검색, 그룹, 메모, 백업 |
| 플레이어 | **도구** | 수면 타이머, 페이지 레이아웃, 보상 자동 청구, 빠른 청구 버튼, 알람 정지, 빠른 작업, 포커스 보기 |
| 경고 | **알림** | 방해 금지, 크기, 지속 시간, 불투명도, 위치, 기록 |
| 경고 | **소리** | 마스터 스위치 및 볼륨, 이벤트별 스위치, 볼륨 및 미리보기 |
| 인터페이스 | **모습** | 테마, 패널 스타일, 강조 색상, 밀도, 대비, 흐림, 텍스트 크기, 언어 |
| 인터페이스 | **애니메이션** | 실시간 미리보기, 사전 설정, 열기/호버/표시기 효과, 속도 |
| 인터페이스 | **바로가기** | 메뉴 단축키 및 작업 단축키 |
| 체계 | **진단** | 실시간 상태, 품질 검사, 충돌 확인, 안전 모드, 작업 로그 |
| 체계 | **데이터 및 정보** | 내보내기, 가져오기, 실행 취소, 재설정, 백업 복원, 링크 |

모든 슬라이더는 마우스를 올려 놓는 동안 마우스 휠에 반응합니다. 패널 상단에 있는 검색 상자를 사용하면 이름으로 설정을 찾을 수 있습니다. 검색은 영어 이름도 이해하므로 모든 인터페이스 언어에서 동일하게 작동하며 거기에 입력된 키는 페이지에 도달하지 않습니다.

## 빠른 청구 버튼

**도구 → 페이지의 빠른 소유권 주장 버튼**에서 활성화하세요. 스트림에 작은 버튼이 나타납니다.

- **어디든지 드래그**하세요. 그 위치가 기억됩니다.
- **클릭**하여 보상을 받으세요(보상 창이 열리고 *청구*를 누른 다음 창을 닫고 스트림으로 돌아갑니다).
- Kick의 보상 알림이 나타나면 **빛나고 빨간색 점으로 표시**됩니다. *보상이 있을 때만 표시*를 켜서 나머지 시간 동안 숨겨두세요.
- **스타일**(Orb, Pill, Glass, Flat), 내장된 **아이콘** 또는 **자신만의 이미지**(최대 2MB의 PNG, JPG, WebP, GIF 또는 SVG, 배경이 투명한 정사각형 이미지가 가장 잘 보입니다), **크기** 및 **불투명도**를 선택하세요. 실시간 미리보기에는 모든 변경사항이 표시됩니다.

이 버튼은 *보상 자동 청구*와 별개이므로 직접, 자동으로 또는 두 가지 모두를 통해 청구할 수 있습니다.

## 문제 해결

- **품질이 적용되지 않습니다.** **진단**을 열고 *진단 새로 고침*을 눌러 Kick이 제공하는 품질을 스캔한 다음 *선택한 품질을 확인하세요*. 채널이 제외되거나 안전 모드가 켜져 있으면 상태 표시줄에 그렇게 표시됩니다.
- **보상은 청구되지 않습니다.** 자동 청구는 기본적으로 꺼져 있습니다. **도구 → 보상**에서 활성화하고 *지금 받기*를 시도해 보세요. 탭이 표시되고 채팅에 입력하지 않는 동안 라이브 채널에서만 작동합니다. *알림* 모드에서 스크립트는 Kick의 보상 배너에 반응합니다.
- **무음 재생 및 오디오.** 무음 재생은 이득이 없는 브라우저의 오디오 엔진을 통해 비디오를 라우팅합니다. 사이트에서 이를 차단하면 패널에서 이를 알리고 일반 사운드는 그대로 유지됩니다.
- **뭔가 이상하게 작동합니다.** *충돌 확인*을 실행하거나 문제의 페이지에서 *섹션 재설정*을 사용하세요.
- **업데이트 후 설정이 잘못된 것 같습니다.** **데이터 및 정보 → 실행 취소** 또는 **백업 복원**을 사용하세요.
- **버그를 발견하셨나요?** *진단 복사*를 누르고 [new issue](https://github.com/ebayybe/kick-stream-tweaks/issues).

## 은둔

설정 및 채널 프로필은 kick.com의 브라우저 로컬 저장소에 저장됩니다. 스크립트는 어디에도 데이터를 보내지 않으며 추가 권한을 요청하지 않습니다(`@grant none`).

## 기여

문제 및 풀 요청을 환영합니다. 스크립트는 단일 독립형 파일이므로 변경을 시도하는 데 빌드 단계가 필요하지 않습니다. `kick-stream-tweaks.user.js` 페이지를 새로고침하세요.
