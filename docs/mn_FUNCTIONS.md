# Kick Stream Tweaks — Функцийн лавлагаа

Kick Stream Tweaks-ийн лавлагаа 1.3.1. Энэ нь функциональ талбар бүр юу хийдэг, тохиргоонууд хэрхэн хадгалагддаг, скрипт нь Kick-ийн хуудасны аль хэсгээс хамаардаг, мөн хэрэглэгчийн скрипт дэх нэрлэгдсэн функц эсвэл арга бүр хэрхэн ажилладаг талаар тайлбарладаг. [Хадгалах газар](https://github.com/ebayybe/kick-stream-tweaks) болон [өөрчлөлтийн бүртгэлийг](../CHANGELOG/en_CHANGELOG.md) үзнэ үү.

> Нэр нь эх сурвалжтай таарч байна. `void` гэдэг нь функц нь гаж нөлөөгөөр үйлчилдэг гэсэн үг юм. `Object.method` гэж бичсэн арга нь тухайн объект дээр амьдардаг ( `PlayerSync` , `Extras` , `GUI` , `Store` ).

## Архитектур

Хэрэглэгчийн скрипт нь `document-start` дээр `@grant none` гэсэн утгатай ажилладаг нэг бие даасан файл юм. Энэ нь бүтээх алхамгүй бөгөөд өөрийн сүлжээний хүсэлтийг гаргадаггүй.

| Давхарга | Объект / талбай | Хариуцлага |
|---|---|---|
| Өгөгдөл | `TR` , `DIAG` , `FLAGS` , `LANG_NAMES` | 38 хэлний орчуулга, орон нутгийн оношилгооны мессеж, туг SVG болон хэлний нэрс. |
| Тохиргоо | `CONFIG` , `DEFAULTS` | Тогтмол (сонгогч, дахин оролдох хязгаар, урьдчилан тохируулга, хэсэг) болон үндсэн тохиргоо. |
| Хадгалах | `sanitizeSettings` , `Store` , `persist` | `localStorage` д тохиргоог баталгаажуулж хадгалдаг; санах ойд буцаах стекийг хадгалдаг. |
| Тоглогчийн логик | `PlayerSync` | Видеог олж, чанар, дууны хэмжээ, хурд, чимээгүй горимыг сэргээж, хөлдсөн эсэхийг хардаг. |
| Хуудасны туслахууд | `Extras` | Бүдүүвчний товчлуурууд, шагнал нэхэмжлэх, сувгийн аватарууд болон дэвсгэр төлөвлөгч. |
| Интерфэйс | `PAGES` , `GUI` , туслахууд | Shadow-DOM самбар, мэдэгдэл, дуу чимээ, хөвөгч хурдан нэхэмжлэлийн товчлуур, товчлуурууд. |

Өгөгдлийн урсгал: 1.5 секундын `PlayerSync.sync` гогцоо нь үр дүнтэй тохиргоог (эхлээд сувгийн профайл, дараа нь глобал) уншиж, тоглуулагчид хэрэглэж, `Extras.tick` руу залгана. Хэрэглэгчийн үйлдэл нь `GUI` зохицуулагчаар дамждаг бөгөөд тэдгээр нь тохиргоог `persist` шинэчилж, зөвхөн нөлөөлөлд өртсөн хэсгийг тоглуулагч руу түлхэж өгдөг ( `media` эсвэл `all` ).

## Хэрэглэгчид хандах хандлага

| Талбай | Зан төлөв |

Хуудасны өөрөө хийсэн өөрчлөлтүүд (жишээ нь, дууны хэмжээг 50% болгон дахин тохируулах өшиглөлт) буцаагдана; Зөвхөн үзэгчийн өөрийн үйлдэл нь хадгалсан утгыг шинэчилдэг. |
| Чанар | Тоглогчийн цэсээр дамжуулан хүссэн чанарыг сонгож, боломжгүй үед дараагийн доод (эсвэл Авто) руу буцаж очоод цэсийг дахин хаадаг. Зөвхөн жинхэнэ хэрэглэгчийн товшилт нь скриптийг шинэ "хамгийн сүүлд ашигласан" чанарыг заадаг. |
| Эзлэхүүн болон чимээгүй тоглуулах | Дууны түвшин болон дууг хаах горимыг урсгал бүрт сэргээдэг. Чимээгүй тоглуулах нь видеог Вэб Аудио хөдөлгүүрээр 0 ашиггүйгээр чиглүүлдэг тул дамжуулалтыг дуугүй болгохгүйгээр арын таб дээр тоглуулсаар байх болно. |
| Сувгийн профайл | **Энэ сувгийг хадгалах нь** үзэж буй сувгийн одоогийн чанар, дууны хэмжээ, хурд, дууг хадгалдаг. Профайл нь мөн тэмдэглэл, бүлгүүд, зүү төлөв, аватар болон идэвхжүүлсэн/хасаагдсан тугуудыг агуулна. |
| Урьдчилсан тохиргоо | Нэг товшилтоор зурвасын өргөн, хамгийн сайн чанар, чимээгүй үзэх, VOD хэмнэнэ. |
| Самбар | `F2` эсвэл тусгай товчлуур нь бүлэглэсэн хажуугийн самбар, хайлт, Kick болон Minimal загвар, цайвар/хар сэдэв, 14 өргөлтийн өнгө, мөн өнгө сонгогч, авсаархан зохион байгуулалт, арын дэвсгэр бүдгэрүүлэх, текстийн масштаб, өндөр тодосгогч болон хөдөлгөөнт дүрс бүхий тогтмол өргөнтэй (680 пиксель) самбарыг нээнэ. |
| Хайх | Өргөлтийн мэдрэмжгүй, интерфэйсийн хэл болон англи нэрэнд таарч, хэсэг эсвэл картын гарчигтай таарч байна. Самбар дээр бичсэн товчлуурын цохилтууд хэзээ ч Kick-ийн халуун товчлууруудад хүрдэггүй. |
| Слайдер | Гулсагч бүр товших, чирэх, гарын сум, хулганы дугуй зэрэгт хариу үйлдэл үзүүлдэг. |
| Дуу | Цэсийн үйлдэл, тохиргооны өөрчлөлт, чанарын амжилт/бүтэлгүйтэл, дууны хэмжээг сэргээхэд зориулсан вэб аудио дохиолол тус бүр нь унтраалга, урьдчилан харах, дууны түвшинтэй. |
| Мэдэгдэл | Чирэх, масштаблах, ил тод болгох, дуугүй болгох (бүү саад бол, чимээгүй бүтэн дэлгэцээр) болон түүхэнд бичиж болох нутагшуулсан мессежүүд. |
| Сэрүүлгийг хөлдөөх | Зогсоосон тоглуулагч эсвэл хар дэлгэцийг илрүүлж, чанга дохиолол тоглуулж (дууны эффектийн унтраалгаас үл хамааран далд таб дээр ч гэсэн) мэдэгдэнэ. |
| Шагнал | Нэмэлт автомат нэхэмжлэл нь Kick-ийн шагналын мэдэгдлийг хүлээж (эсвэл хуваарийн дагуу ажилладаг), урамшууллын цонхыг нээж, боломжтой зүйлийг нэхэмжилж, хаадаг. Хөвөгч, чирж болох хурдан нэхэмжлэлийн товчлуур нь нэг товшилтоор ижил үйлдлийг гүйцэтгэдэг. |
| Зохион байгуулалт | Чатыг нууж, самбар эсвэл товчлуурын зүүн цэсийг буулгаж, дамжуулалт бүрийн сонголтыг санах боломжтой. |
| Хэрэгсэл | Унтлагын цаг хэмжигч, фокус (бүрэн дэлгэц) харах, тоглуулагчийг дахин синк хийх, автомат өөрчлөлт бүрийг түр зогсоодог аюулгүй горим. |
| Оношлогоо | Амьд байдал, илрүүлсэн чанар, видео нягтрал, чанарын скан, зөрчил шалгах, үйлдлийн бүртгэл, хуулбарлах тайлан. |
| Өгөгдөл | Тохиргоог экспортлох/импортлох, буцаах, дахин тохируулсны дараа сэргээх, хадгалсан сувгуудыг нөөцлөх/сэргээх. |
| Нууцлал | Тохиргоо, профайл, бүртгэл, түүх нь хөтчийн санд үлдэнэ. Хаашаа ч юу ч илгээгээгүй. |

Товчлуурын хослолууд нь `Alt+Q` гэх мэт тэмдэгт мөр хэлбэрээр хадгалагдаж, физик товчлуураар таардаг тул гарны дурын загварт ажиллах боломжтой. Самбарын өргөнийг 680 пикселээр тогтооно (цонхны хэмжээгээр хязгаарласан); өмнөх өргөн тохиргоог үл тоомсорлодог.

<a id="kick-page-dependencies"></a>
## Хуудасны хамаарлыг өшиглөх

Скрипт нь Kick-ийн одоогийн тэмдэглэгээнд тулгуурладаг. Боломжтой бол энэ нь харагдах текстээс илүү дүрс, шинж чанар, бүтцийг ашигладаг тул интерфэйс бүрийн хэл дээр үргэлжлүүлэн ажилладаг. Хэрэв Kick эдгээрийг өөрчилвөл тохирох функц ажиллахаа болино (үлдсэн хэсэг нь ажилласаар байх болно).

| Онцлог | Энэ нь юу хайж байна |
|---|---|
| Чанар | Харагдах `<video>` , тоглуулагчийн `button[aria-haspopup="menu"]` болон `[role="menuitemradio"]` оруулгууд. |
| Зохион байгуулалт | `data-sidebar` болон `data-chat` , `[data-testid="sidebar-collapse"]` / `sidebar-expand` , `#channel-chatroom` доторх `CollapseRight` дүрс тэмдгийн товчлуур болон чатыг харуулах `MessagesOutline` дүрс тэмдэг бүхий контейнер. |
| Шагналын мэдэгдэл | Эх сурвалж нь `reward-available` , эсвэл `daily-rewards` видео агуулсан `[role="group"]` карт агуулсан `video` . |
| Шагнал нэхэмжилж байна | `button[aria-haspopup="dialog"][aria-controls]` (бэлэгний дүрс), түүний удирддаг харилцах цонх ( `data-state` ), `.contents` хүүхэд бүхий нэхэмжлэлийн товчлууруудыг идэвхжүүлсэн, `.sr-only` шошготой хаах товчлуур. |

| Аватар | `img[alt]` элементүүдийн эх сурвалж нь `files.kick.com/images/user/…/profile_image/…` . |

## Нутагшуулалт

Шошго, тусламжийн мессеж, алдаа, харилцах цонх, мэдэгдэл бүр 38 хэлний орчуулагчаар дамждаг. Алга болсон түлхүүрүүд англи хэл рүү буцдаг. Шинэ интерфэйсийн текстийг нэмсэн функцийн хамт дэмжигдсэн бүх хэл рүү орчуулсан. Хэл сонгогч нь туг болон төрөлх нэрийг харуулдаг; Интерфэйс нь эхний ээлжинд хөтчийн хэлийг дагаж, дараа нь тодорхой сонголтыг санах болно.

## Аюулгүй байдал, нууцлал, нийцтэй байдал

- Хадгалахын өмнө тохиргоог ариутгасан; хүчингүй утгууд аюулгүй өгөгдмөл рүү буцна.
- Сувгийн нэр, тэмдэглэл, мэдэгдлийн текст болон оношилгооны гаралтыг HTML оруулахаас өмнө орхисон.
- Тусгай товчлуурын дүрсийг зотон дээрээс дахин кодлож, зөвхөн зөвшөөрөгдсөн зургийн төрлийн өгөгдлийн URL хэлбэрээр хадгална; Энэ нь хөтчөөс хэзээ ч гарахгүй.
