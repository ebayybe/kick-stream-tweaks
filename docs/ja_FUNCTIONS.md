# キックストリームの微調整 — 関数リファレンス

Kick Stream Tweaks 1.3.1 のリファレンス。ここでは、各機能領域が何を行うか、設定がどのように保存されるか、スクリプトが Kick のページのどの部分に依存するか、およびユーザー スクリプト内の各名前付き関数やメソッドがどのように機能するかについて説明します。[リポジトリ](https://github.com/ebayybe/kick-stream-tweaks)と[変更ログを](../CHANGELOG/en_CHANGELOG.md)参照してください。

>名前はソースと一致します。 `void` 、関数が副作用を通じて動作することを意味します。 `Object.method`として記述されたメソッドは、そのオブジェクト上に存在します ( `PlayerSync` 、 `Extras` 、 `GUI` 、 `Store` )。

## 建築

ユーザースクリプトは、 `@grant none`を使用して`document-start`で実行される 1 つの自己完結型ファイルです。ビルドステップがなく、独自のネットワーク要求も行いません。

|レイヤー |オブジェクト / エリア |責任 |
|---|---|---|
|データ | `TR` 、 `DIAG` 、 `FLAGS` 、 `LANG_NAMES` | 38 言語の翻訳、ローカライズされた診断メッセージ、フラグ SVG、および言語名。 |
|構成 | `CONFIG` 、 `DEFAULTS` |定数 (セレクター、再試行制限、プリセット、セクション) とデフォルト設定。 |
|ストレージ | `sanitizeSettings` 、 `Store` 、 `persist` |設定を検証して`localStorage`に保存します。メモリ内に元に戻すスタックを保持します。 |
|プレーヤーのロジック | `PlayerSync` |ビデオを検索し、品質、音量、速度、サイレント モードを復元し、フリーズを監視します。 |
|ページヘルパー | `Extras` |レイアウト ボタン、報酬の受け取り、チャンネル アバター、およびバックグラウンド スケジューラー。 |
|インターフェース | `PAGES` 、 `GUI` 、ヘルパー | Shadow-DOM パネル、通知、サウンド、フローティングクイッククレームボタン、ホットキー。 |

データ フロー: 1.5 秒の`PlayerSync.sync`ループは、有効な設定 (最初にチャネル プロファイル、次にグローバル) を読み取り、それらをプレーヤーに適用し、 `Extras.tick`を呼び出します。ユーザーアクションは`GUI`ハンドラーを経由して、設定を`persist`に更新し、影響を受ける部分のみをプレーヤー ( `media`または`all` ) にプッシュします。

<a id="user-facing-behavior"></a>
## ユーザー向けの動作

|エリア |行動 |
|---|---|
|プレイヤーの粘り強さ |ライブ/VOD の品質、音量、ミュート状態、サイレント モード、速度を保存し、新しいストリームが検出されたときにそれらを適用します。ページ自体が行った変更 (たとえば、キックで音量を 50% にリセット) は元に戻されます。保存された値は、閲覧者自身のアクションによってのみ更新されます。 |
|品質 |プレーヤーのメニューから優先品質を選択し、使用できない場合は次の低い品質 (または自動) に戻り、メニューを再度閉じます。本物のユーザーのクリックだけがスクリプトに新しい「最後に使用された」品質を教えます。 |
|音量とサイレント再生 |音量とミュートはストリームごとに復元されます。サイレント再生では、ビデオがゼロ ゲインで Web オーディオ エンジンにルーティングされるため、ストリームはミュートされずにバックグラウンド タブで再生され続けます。 |
|チャンネルプロフィール |**このチャンネルを保存すると、**視聴しているチャンネルの現在の品質、音量、速度、サウンドが保存されます。プロファイルには、メモ、グループ、ピンの状態、アバター、有効/除外フラグも保持されます。 |
|プリセット |帯域幅を節約し、最高の品質で、静かな視聴と、ワンクリックで VOD を適用できます。 |
|パネル | `F2`またはカスタム ホットキーを押すと、グループ化されたサイドバー、検索、キック スタイルとミニマル スタイル、明るい/暗いテーマ、14 個のアクセント カラーとカラー ピッカー、コンパクトなレイアウト、背景ぼかし、テキスト スケーリング、ハイ コントラスト、アニメーション コントロールを備えた固定幅 (680 ピクセル) パネルが開きます。 |
|検索 |アクセントを区別せず、インターフェイス言語と英語名に一致し、セクションまたはカードのタイトルに一致します。パネルに入力されたキーストロークが Kick のホットキーに到達することはありません。 |
|スライダー |すべてのスライダーは、クリック、ドラッグ、キーボードの矢印、マウス ホイールに反応します。 |
|音 |メニュー操作、設定の変更、品質の成功/失敗、音量の復元の Web オーディオ キュー。それぞれにスイッチ、プレビュー、音量が付いています。 |
|お知らせ |ローカライズされたメッセージは、ドラッグ、拡大縮小、透明化、消音 (邪魔しないで、全画面表示) したり、履歴に記録したりすることができます。 |
|フリーズアラーム |停止したプレーヤーまたは黒い画面を検出し、大音量のアラームを再生し (効果音スイッチとは関係なく、非表示のタブでも)、通知を表示します。 |
|報酬 |オプションの自動請求は、Kick の報酬通知を待ち (またはスケジュールに従って実行し)、報酬ウィンドウを開き、利用可能なものを請求して閉じます。フローティングのドラッグ可能なクイッククレーム ボタンも、ワンクリックで同じことを行います。 |
|レイアウト |チャットを非表示にし、パネルまたはホットキーを使用して左側のメニューを折りたたんで、オプションでストリームごとの選択を記憶します。 |
|ツール |スリープ タイマー、フォーカス (全画面) ビュー、プレーヤーの再同期、およびすべての自動変更を一時停止するセーフ モード。 |
|診断 |ライブステータス、検出された品質、ビデオ解像度、品質スキャン、競合チェック、アクションログ、およびコピー可能なレポート。 |
|データ |設定のエクスポート/インポート、アンドゥ、リセット後の復元、保存したチャンネルのバックアップ/復元。 |
|プライバシー |設定、プロファイル、ログ、履歴はブラウザのストレージに残ります。どこにも何も送信されません。 |

## 設定リファレンス

すべての値は`sanitizeSettings`によって検証されます。無効なものはデフォルトに戻ります。範囲が強制されます。

### プレーヤー

|キー |種類/範囲 |デフォルト |意味 |
|---|---|---|---|
| `autoQualityEnabled` |ブール値 | `true` |優先品質を自動的に適用します。 |
| `preferredLiveQuality` 、 `preferredVodQuality` | `auto` 、 `1080p60` 、 `1080p` 、 `720p` 、 `480p` 、 `360p` `160p` `auto` |ライブ ストリームや VOD に適用できる品質。 `auto` 「最後の選択を記憶する」という意味です。 |
| `lastLiveQuality` 、 `lastVodQuality` |同じ | `auto` |視聴者が手で選んだ最後の品質。 |
| `qualityFallback` | `lower` 、 `auto` | `lower` |推奨される品質が提供されない場合の対処方法。 |
| `autoVolumeEnabled` |ブール値 | `true` |保存されたボリュームを復元して保護します。 |
| `volume` | 0–1 | `1` |保存されたボリューム。 |
| `muted` |ブール値 | `false` |ミュート状態を保存しました。 |
| `silent` |ブール値 | `false` |サイレント再生 (ゼロゲインオーディオグラフ、プレーヤーはミュートされていません)。 |
| `playbackRate` | 0.25～2.5 | `1` |保存された速度; `1`は決して強制されるものではありません。 |
| `warnLoudVolume` 、 `loudVolumeThreshold` |ブール値; 60–100、ステップ 5 | `true` ; `85` |大音量警告。 |
| `safeMode` |ブール値 | `false` |すべての自動変更を一時停止します。 |
| `channelProfiles` |オブジェクト、最大 200 | `{}` |チャネルごとのプロファイル (以下を参照)。 |

チャンネルプロファイルフィールド： `enabled` 、 `excluded` 、 `liveQuality` 、 `vodQuality` 、 `volume` 、 `muted` 、 `silent` 、 `playbackRate` 、 `displayName` 、 `pinned` 、 `avatar` （ `https://…kick.com/images/user/…` URLのみ）、 `note` （240文字）、 `group` （40文字）、 `updatedAt` 、 `lastUsed` 。

<a id="settings-storage"></a>
## 設定ストレージ

|機能 |パラメータ / 戻り値 |何をどのように行うのか |
|---|---|---|
| `sanitizeProfiles` |オブジェクト → オブジェクト |有効なキーを含むプロファイルを最大 200 個保持し、各フィールドをクランプします。アバターはキック画像 URL である必要があります。 |
| `sanitizeSettings` |オブジェクト、withBackup → オブジェクト |すべての設定 (タイプ、範囲、許可される値) を検証し、1.1 ～ 1.3 の設定 (従来の品質、ホットキー、アニメーション、セクション キー) を移行し、言語ルールを適用します。 |

| `open` 、 `close` 、 `toggle` | — → 無効 |パネル、ポーリング、フォーカス、メニュー音を制御します。 |

<a id="hotkeys-and-startup"></a>
## ホットキーと起動

|機能 |パラメータ / 戻り値 |何をどのように行うのか |
|---|---|---|
| `isolateKeys` | — → 無効 |キャプチャ フェーズの`document-start`時に登録されます。パネル内からのキーボード イベントはキックへの伝播を停止し (スペース、F、M および矢印がプレーヤーのホットキーをトリガーすることはありません)、タブはダイアログ内に閉じ込められます。 |
| `setupHotkeys` | — → 無効 |再バインド、エスケープ (モーダル、ドロップダウン、パネル)、メニュー ホットキー、およびアクション ホットキーのためのキー キャプチャを処理します。修飾キーまたは F キーを使用したコンボは、入力中でも機能します。 |
| `init` | — → 無効 |パネルを構築し、ホットキーをインストールし、 `PlayerSync`を開始します。二重注入を防ぎます。 |

<a id="kick-page-dependencies"></a>
## ページの依存関係をキックする

スクリプトは Kick の現在のマークアップに依存しています。可能な限り、目に見えるテキストではなくアイコン、属性、構造を使用するため、あらゆるインターフェイス言語で動作し続けます。 Kick がこれらを変更すると、マッチング機能は動作しなくなります (残りの機能は動作し続けます)。

|特集 |何を求めているのか |
|---|---|
|品質 |表示可能な`<video>` 、プレーヤーの`button[aria-haspopup="menu"]`および`[role="menuitemradio"]`エントリ。 |
|レイアウト | `data-sidebar`と`data-chat` 、 `[data-testid="sidebar-collapse"]` / `sidebar-expand` 、 `#channel-chatroom`内の`CollapseRight`アイコン ボタン、およびチャットを表示するための`MessagesOutline`アイコン ボタンを含むコンテナー。 |
|特典のお知らせ |ソースに`reward-available`が含まれる`video` 、または`daily-rewards`ビデオを含む`[role="group"]`カード。 |
|報酬請求 | `button[aria-haspopup="dialog"][aria-controls]` (ギフト アイコン)、それが制御するダイアログ ( `data-state` )、. `.contents`子を持つ要求ボタンと`.sr-only`ラベルを持つ閉じるボタンが有効になりました。 |
|ドロップ | `#rewards-panel`リスト項目には、 `[role="progressbar"][data-state="complete"]`と有効なボタンが含まれます。 |
|アバター | `img[alt]`要素のソースは`files.kick.com/images/user/…/profile_image/…`です。 |

<a id="localization"></a>
## ローカリゼーション

すべてのラベル、ヘルプ メッセージ、エラー、ダイアログ、および通知は、38 のロケールの翻訳リゾルバーを通過します。キーが見つからない場合は英語に戻ります。新しいインターフェイス テキストは、それを追加する機能とともに、サポートされているすべての言語に翻訳されます。言語セレクターにはフラグとネイティブ名が表示されます。インターフェイスは最初の実行時にブラウザ言語に従い、その後は明示的な選択を記憶します。

<a id="safety-privacy-and-compatibility"></a>
## 安全性、プライバシー、互換性

-設定は保存前にサニタイズされます。無効な値は安全なデフォルトに戻ります。
-チャネル名、メモ、通知テキスト、および診断出力は、HTML 挿入前にエスケープされます。
-カスタム ボタン アイコンはキャンバスから再エンコードされ、許可された画像タイプのみのデータ URL として保存されます。ブラウザから離れることはありません。
- Shadow DOM は、スクリプトのスタイルを Kick から分離します。パネルからのキーボード イベントは、Kick のホットキーから分離されます。
-自動アクションにより、除外されたチャンネル、セーフ モード、欠落しているプレーヤー要素がスキップされます。報酬の請求は 1 回の実行で同じボタンを 2 回押すことはなく、視聴者が入力するまで待機します。
-スクリプトはネットワーク要求を行いません。更新はユーザースクリプトマネージャーまたはリリースページから行われます。
- 1.1.0、1.2.0、1.3.0 から移行する場合、既存のローカル設定は保持されます。
