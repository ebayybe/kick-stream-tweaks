# Kick Stream Tweaks — سجل التغييرات

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## إصدار 1.2.0 — 2026-10-07

يوسّع هذا الإصدار أدوات حفظ الجودة والصوت لتشمل إعدادات المشغل والقنوات.

### Added

يتضمن ملفات تعريف لكل قناة، وقائمة قنوات محفوظة، ومؤثرات صوتية وإشعارات وسجلًا للتشخيص. أُضيفت أوضاع العرض والمؤقت والاختصارات وإمكانية استيراد الإعدادات وتصديرها ودعم لوحة المفاتيح وإمكانية الوصول.

### Fixed

إصلاح عرض النوافذ الفارغة والمتزامنة، والتعامل مع الإشعارات الفارغة والنصوص الطويلة واستبدال متغيرات الجودة.

### Compatibility

تُحفظ الإعدادات الحالية عند الترقية من 1.1.0. تبقى البيانات محلية؛ وفاحص التحديثات لا يثبت الإصدارات تلقائيًا.
