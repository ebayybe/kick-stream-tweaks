# Kick Stream Tweaks — 變更記錄

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## 1.2.0 版本 — 2026-10-07

此版本將畫質與音量記憶功能擴充為完整的播放器及頻道設定工具。

### 功能

新增頻道設定檔與已儲存頻道、音效、通知及診斷功能，並提供面板樣式、睡眠計時器、快速鍵、匯入/匯出、鍵盤導覽與無障礙選項。

### 修复

修正空白或重疊視窗、空白通知、過長標籤及畫質佔位符替換問題。

### 兼容性

從 1.1.0 升級時會保留設定。資料僅儲存在本機；更新檢查不會自動安裝新版。
