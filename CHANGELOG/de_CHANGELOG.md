# Kick Stream Tweaks — Änderungsprotokoll

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## Version 1.2.0 — 2026-10-07

Diese Version erweitert das Speichern von Qualität und Lautstärke zu einem umfassenden Player- und Kanal-Einstellungspaket.

### Added

Enthält Kanalprofile und gespeicherte Kanäle, Soundeffekte, Benachrichtigungen und Diagnose. Dazu kommen Panelstile, Timer, Tastenkürzel, Import und Export, Tastatursteuerung und Bedienungshilfen.

### Fixed

Anzeige leerer und gleichzeitig geöffneter Fenster, leerer Benachrichtigungen, langer Beschriftungen sowie Platzhalter für Qualität korrigiert.

### Compatibility

Einstellungen bleiben beim Update von 1.1.0 erhalten. Daten bleiben lokal; die Updateprüfung installiert nichts automatisch.
