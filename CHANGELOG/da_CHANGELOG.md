# Kick Stream Tweaks — Ændringslog

[Kick Stream Tweaks](https://github.com/ebayybe/kick-stream-tweaks)

## Version 1.2.0 — 2026-10-07

Denne version udvider lagring af kvalitet og lydstyrke til et komplet sæt afspiller- og kanalindstillinger.

### Added

Tilføjer kanalprofiler og gemte kanaler, lydeffekter, meddelelser og diagnosticering. Derudover kommer paneltypografier, timer, genveje, import og eksport, tastaturstyring og tilgængelighedsfunktioner.

### Fixed

Rettet visning af tomme og samtidige vinduer, tomme meddelelser, lange etiketter og erstatning af kvalitetspladsholdere.

### Compatibility

Indstillinger bevares ved opgradering fra 1.1.0. Data forbliver lokalt; opdateringstjekket installerer ikke automatisk.
